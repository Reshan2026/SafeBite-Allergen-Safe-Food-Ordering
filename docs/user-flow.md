# User Flow

1. **Home** → Set Allergy Profile or Explore Food.
2. **Allergy Profile** → select allergens → Save → confirmation message.
3. **Restaurants** → filter by cuisine, vegetarian, vegan, delivery time → View menu.
4. **Menu** → each dish shows status badge, allergens, ingredients.
   - Green → Add to Cart.
   - Yellow → review dialog → Add after review, Contact restaurant, or Find Safer Alternatives.
   - Red → ALLERGEN ALERT → Remove Item or Find Safer Alternatives (not added).
5. **Customize** (optional) → remove ingredients, toppings, size, notes → live status → Add to Cart.
6. **Cart** → quantities, totals, status per item. Red items block checkout.
7. **Checkout** → name, phone, address, payment → final allergen check → review checkbox if caution items → Place order.
8. **Confirmation** → order ID, items, total, ETA → Back to Home.
9. **Dashboard** → profile, saved allergies, previous orders, edit profile, logout.

```
Home → Profile → Restaurants → Menu ⇄ Customize → Cart → Checkout → Confirmation → Dashboard
                                  ↘ Red: blocked → Safer alternatives
```
